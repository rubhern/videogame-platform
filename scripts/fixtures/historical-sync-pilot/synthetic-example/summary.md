## Method

- `measured`: read from the durable run report, PostgreSQL, Docker or the application's own meters.
- `estimated`: arithmetic on measured values; `unavailable`: not observed, never filled in.
- Samples are point readings; a sampled maximum is a lower bound of the true peak.
- CPU percent is Docker's per-container figure where 100 % is one core. Bytes are binary multiples.
- Meter deltas are process-cumulative and include anything else the application did meanwhile.
- `methodology.json` in this directory gives every `samples.csv` column with its unit.
