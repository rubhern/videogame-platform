VideoGame Platform Learning MVP API (1.2.0)

Download OpenAPI specification:

Browser-facing API for the approved learning MVP vertical slice.

Provider-independent, same-origin contract for release discovery, bounded-catalogue search, public game details, BFF session discovery, and the authenticated user's ratings. It contains only the nine approved method/path operations.

Authentication navigation under /auth and catalogue synchronization are separate BFF and operational boundaries and are intentionally not exposed here. Provider image binaries are loaded from an approved CDN reference or replaced by a product-owned fallback; this API does not copy, proxy, or redistribute them.

Releases

Public recent and upcoming release discovery.

Browse recent or upcoming releases

Reads a bounded page from the last valid local catalogue publication. The application derives the evaluation date and release window in Europe/Madrid. Empty, stale, review-required, imprecise-date, TBA, and fallback-cover results are valid states. PostgreSQL applies filters, total ordering, count, limit, and offset.

Catalogue

Public reads from the bounded local catalogue.

Search the bounded catalogue

Searches canonical titles and approved aliases after trimming. Matching is case- and diacritic-insensitive, requires every token, and is non-fuzzy. It never calls a provider. Zero and multiple matches are valid outcomes.

q
required
string [ 1 .. 100 ] characters .*\S.*
Example: q=resident evil 4

Trimmed query containing 1 to 100 Unicode code points.

page
integer >= 1
Default: 1

One-based page; a page beyond the last returns an empty page.

pageSize
integer [ 1 .. 100 ]
Default: 20
