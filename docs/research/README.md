  and validation plan; not user evidence.
- [Metacritic journey comparison](competitor-journey-comparison-metacritic.md):

## Remaining evidence

- authenticated IGDB sample results against owner-confirmed acceptance metrics;
- recorded terms for the non-commercial PoC and any clarification required before
  public or monetized use, especially attribution, retained data, and images;
- lightweight prototype usability evidence;
- links from observed evidence to `docs/product/assumptions.md`.

Do not commit personal data, credentials, provider secrets, or material that cannot be
stored in this repository.
