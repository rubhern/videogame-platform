# Metacritic journey comparison

- **Status:** Historical discovery evidence
- **Observed:** 2026-07-23
- **Scope:** Public Metacritic game pages and release/discovery navigation

## Question

Could the learning MVP offer a coherent narrow value without attempting to reproduce
Metacritic's catalogue breadth or professional score aggregation?

## Observations

- Metacritic is strong at recognizable game pages, professional/user score context,
  editorial content, and broad catalogue navigation.
- Release discovery, platform/region precision, provenance/freshness, and continuity
  into a retrievable personal rating are not presented as one focused Spanish-first
  journey.
- A professional aggregate is a licensed/editorial product capability, not a generic
  number the MVP may copy or reconstruct.
- Breadth and authority are established competitor strengths; matching them is not a
  credible MVP objective.

## Product implication

The defensible learning hypothesis is a smaller flow:

```text
relevant release context -> concise game page -> personal rating -> later retrieval
```

Potential differentiation comes from Spanish-first copy, platform/region-aware
commercial releases, explicit date precision/provenance, and the complete personal
rating loop. It does not come from recreating Metascore, scraping reviews, or claiming
better catalogue coverage.

This comparison supports a hypothesis, not market demand. Product scope remains
owned by the [Product Brief](../product/product-brief.md); current competitor behaviour
must be re-observed before using this document for a new decision.
