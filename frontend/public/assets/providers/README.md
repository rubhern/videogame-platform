# Provider attribution assets

`igdb.svg` is the white IGDB mark downloaded from the inline SVG in the official
[IGDB API documentation](https://api-docs.igdb.com/) on 2026-10-14. Its five path
definitions and white fill are preserved. Page-specific classes, dimensions and
CSS were removed; the viewBox fits the complete mark with a small clear margin.
It contains no scripts, fonts, links or external resources.

or endorsement. The mark stays white, proportional and separate from Gameómetro's
identity; each score links to its own source work and is named “Jugadores IGDB”.
